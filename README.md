# AeroHub Connector — Releases

Installers and updates for **AeroHub Connector**, the Windows app that shows your Infinite Flight flight on Discord.

Download the latest version from the [Releases](https://github.com/valdemarbanganga13/aerohub-connector-releases/releases/latest) page.

The app updates itself automatically. This repository only holds the published builds; it contains no source code.

More at [connector.aerohubradar.com](https://connector.aerohubradar.com).
